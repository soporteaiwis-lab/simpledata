🧠 ¿Qué son los LLMs (Large Language Models)?

Los Modelos de Lenguaje Grandes (LLMs) son sistemas de inteligencia artificial entrenados con enormes cantidades de texto para comprender y generar lenguaje humano. Son como "motores de texto ultra-avanzados" que aprenden patrones, contextos y relaciones en el lenguaje a través de miles de millones de parámetros.

🔬 ¿Cómo funciona un LLM por dentro?

1️⃣

Tokenización

El texto se divide en "tokens" (palabras o subpalabras). Por ejemplo: "ChatGPT es increíble" → ["Chat", "G", "PT", "es", "increíble"]

2️⃣

Embeddings

Cada token se convierte en un vector numérico de alta dimensión que captura su significado semántico

3️⃣

Capas de Transformers

Los vectores pasan por múltiples capas de "attention" que aprenden relaciones contextuales entre palabras

4️⃣

Predicción

El modelo predice el siguiente token más probable basándose en todo el contexto anterior

5️⃣

Generación Iterativa

Se repite el proceso token por token hasta completar la respuesta

🔄 Flujo de una Consulta (Inferencia)

1

Request HTTP

Tu prompt llega al servidor vía API REST o WebSocket

2

Load Balancing

Sistema distribuye la carga entre múltiples servidores GPU

3

Tokenización

Texto se convierte en tokens numéricos

4

Modelo GPU

GPU procesa tokens a través de billones de parámetros

5

Generación Autoregresiva

Modelo genera tokens uno por uno, prediciendo el siguiente más probable

6

Moderación

Filtros de seguridad revisan la salida antes de entregarla

7

Response Streaming

Respuesta se envía token por token para experiencia en tiempo real

⏱️ Tiempo total: 2-5 segundos típicamente | Latencia por token: 20-50ms

⚡ Actividad Práctica: "El Email Perfecto para BCI"

Pon a prueba ChatGPT, Claude y Gemini en un caso real de prospección

📋 Escenario

Has identificado a María González, nueva Gerente de Transformación Digital en BCI Banco, que podría estar interesada en servicios de consultoría en IA para optimizar procesos de atención al cliente.

Tu tarea: usar ChatGPT, Claude y Gemini para redactar un correo de presentación breve, personalizado y de alto impacto.

📝 Instrucciones Paso a Paso

1

Define tu prompt base

"Redacta un email de presentación profesional para María González, nueva Gerente de Transformación Digital en BCI Banco. El objetivo es ofrecer servicios de consultoría en IA para optimizar procesos de atención al cliente. El email debe ser breve (máximo 150 palabras), personalizado, y generar interés para agendar una reunión. Incluye un subject line atractivo."

2

Prueba con cada modelo

Usa el mismo prompt en:

🤖 ChatGPT

chat.openai.com

🧠 Claude

claude.ai

✨ Gemini

gemini.google.com
3

Analiza y compara

Evalúa cada respuesta según estos criterios:

  • ▸ Personalización: ¿Menciona detalles específicos de BCI o transformación digital?
  • ▸ Brevedad: ¿Respeta el límite de 150 palabras?
  • ▸ Tono profesional: ¿Es apropiado para un ejecutivo bancario?
  • ▸ Call-to-action: ¿Incluye un cierre claro para agendar reunión?
  • ▸ Subject line: ¿Es atractivo y relevante?
4

Itera y mejora

Con el modelo que tuvo mejor resultado, refina tu prompt:

Ejemplos de mejoras:

  • • "Hazlo más conciso, máximo 100 palabras"
  • • "Incluye un dato específico sobre BCI que investigué"
  • • "Cambia el tono a más consultivo y menos comercial"
  • • "Agrega una pregunta de apertura impactante"
